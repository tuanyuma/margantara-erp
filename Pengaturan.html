Database & Cloud Sync (Supabase Hybrid)

STANDBY / INACTIVE

Arsitektur Dual-Database: Supabase PostgreSQL sebagai database realtime berkecepatan tinggi, dan Google Sheets sebagai backup otomatis.

Dapatkan URL dari dashboard Supabase: Project Settings > API > Project URL.

Server-Side Only

Dapatkan dari Project Settings > API > Project API keys > service_role (secret).

Privasi Terproteksi: Kunci rahasia telah ditransfer dan tersimpan aman di Properti Skrip Google Apps Script. Kunci tidak terekspos ke publik atau browser client.
Aktifkan Cloud Sync Supabase
Dual-write otomatis setiap ada CRUD
Transfer Kredensial ke Properti Skrip (Server-Side)
Memindahkan URL & Service Role Key langsung ke Script Properties Google Apps Script agar privasi terjaga 100% dan tidak ter-hardcode.
Langkah 1: Siapkan Tabel di Supabase (DDL SQL 1-Klik)
Klik tombol di samping untuk menyalin query CREATE TABLE lengkap untuk seluruh tabel sistem. Buka SQL Editor di dashboard Supabase Anda, paste query, dan klik Run.
Buka Supabase
Langkah 2: Migrasi & Import Seluruh Data ke Supabase Otomatis 100%
Menyalin seluruh data master, produk, outlet, kunjungan, absensi, dan riwayat transaksi dari Google Sheets langsung ke Supabase dalam hitungan detik tanpa membuka database.
Anti-Pause 6 Hari: Menjaga database Supabase Free Tier tetap hidup dan mencegah auto-pause jika toko/sales libur/tidak ada aktivitas.
